引擎

这是「配置档案之上的一层覆盖」，用来临时换个模型而不改档案本身。 切换配置档案时，如果这个名字在新档案里不存在，会被自动清掉（否则必然请求一个不存在的模型）。

模型配置

每条配置 = 一套 API 地址 + 令牌 + 模型，切换立刻生效。 默认只作用于本应用：启动会话时用 --settings 指定一份独立的配置， 再挡掉用户级设置，所以不会动你全局的 ~/.claude/settings.json。

工作目录

Claude Code 的会话与「项目记忆」都是按工作目录分组的。 同一个工作目录下的新对话会共享项目记忆——它会把事实自动写进 ~/.claude/projects/<目录>/memory/ 并在后续每个会话里加载。 想得到完全干净的上下文，就换一个工作目录。
